# Aura Auth

**Aura Auth** — это Steam Desktop Authenticator (SDA) для Windows: десктопное приложение
на Electron, которое заменяет мобильное приложение Steam Guard для управления аккаунтами
Steam прямо с компьютера. Вход по 2FA, подтверждение трейдов и входов, массовая отправка
предметов, контракты CS2 Trade-Up, просмотр инвентаря и фоновая «игра» в игры — всё в одном
окне, с поддержкой нескольких аккаунтов и прокси для каждого из них.


---

## Возможности

### Учётные записи и 2FA
- **Импорт аккаунта** через `maFile` (перетаскивание файла или выбор через диалог).
- **Код Steam Guard** с обратным отсчётом, копируется в буфер одним кликом.
- **Авто-подтверждение** 2FA-подтверждений (торги, смена email и т.п.).
- **Подтверждение запросов входа** в Steam — как в мобильном приложении: одной кнопкой
  одобряете или отклоняете вход с нового устройства.
- **Переименование** аккаунта (понятная метка вместо технического имени).
- **Выход** и **удаление** аккаунта.
- **Прокси для каждого аккаунта** (см. ниже).

### Трейды и подтверждения
- Список **входящих и исходящих** предложений обмена с фильтрацией.
- **Принять / отклонить** предложение прямо из списка.
- **Авто-приём** трейдов (без ручного подтверждения).
- Окно **деталей предложения** (состав, партнёр, статус) открывается в отдельном окне.
- Лента **подтверждений** с кнопкой «Принять все».

### Массовая отправка предметов
- Выбор предметов из инвентаря и отправка **выбранному аккаунту**.
- **Сохранённые получатели**: SteamID64 или трейд-ссылка + торговый токен.
- Подсказка про ошибку 15 (если получатель не в друзьях и не указан токен).

### Контракты CS2 (Trade-Up)
- Просмотр **инвентаря CS2** и исполнение **Trade-Up контрактов** (10 предметов одной редкости)
  через GlobalOffensive Coordinator (GC).
- Расчёт **EV** контракта, **история** исполненных контрактов.
- Режим просмотра **без запуска игры** (GC недоступен → крафт отключён, видна только аналитика).

### Инвентарь
- Отдельное окно просмотра инвентаря по `appId` / `contextId`, поиск, фильтр «только трейдовые»,
  выделение предметов для массовой отправки.

### Фоновая «игра» в игры
- Подключение к Steam как CM-клиент (через `SteamUser`) и **отчёт об играх** без запуска
  самой игры (как в ASF).
- Выбор конкретных `appID` (пресеты CS2 / Dota 2 / TF2 / Rust + свои) и **авто-игра при запуске**.

### Прокси (настройка на аккаунт)
- Поле **Прокси** в карточке аккаунта и при добавлении: `socks5://`, `socks4://`, `http(s)://`
  или просто `host:port`. Поддерживаются **логин и пароль** (формат продавцов
  `host:port:user:pass` тоже работает).
- Кнопка **«Проверить»** — реальный запрос через прокси и показ внешнего IP (доказывает,
  что трафик идёт через прокси).
- DNS резолвится **на стороне прокси** (схема `socks5h`/`socks4a`), без утечки DNS.

### Интерфейс и настройки
- **Два языка**: русский и английский (переключаются в настройках).
- **Темы оформления**: набор готовых тем (по умолчанию «Aura», тёмные варианты, напр. Midnight).
- **Журнал** событий (сворачиваемая панель) для диагностики.
- **Обновления**: проверка и установка через GitHub Releases (electron-updater).
