# 🛡️ Aura Auth

> 🇷🇺 Русская версия описания. [🇬🇧 English version](README.en.md)

![Built with](https://img.shields.io/badge/built%20with-Electron-47848f)
![Languages](https://img.shields.io/badge/languages-RU%20%7C%20EN-2ecc71)

**Aura Auth** — это Steam Desktop Authenticator (SDA) для Windows. Это приложение заменяет
мобильное приложение Steam Guard и позволяет управлять аккаунтами Steam прямо с компьютера:
вход по 2FA, подтверждение трейдов и входов, массовая отправка предметов, контракты CS2
Trade-Up, просмотр инвентаря и фоновая «игра» в игры — в одном окне, с поддержкой нескольких
аккаунтов и отдельным прокси для каждого.

> 🔒 **Приватность:** ваши `maFile` (ключи 2FA) и токены хранятся **только на вашем компьютере**
> в папке `maFiles/`. Они не передаются в сеть и не загружаются в репозиторий.

---

## ✨ Возможности

### 🔐 Учётные записи и 2FA
- **Импорт аккаунта** через `maFile` (перетащите файл или выберите через диалог).
- **Код Steam Guard** с обратным отсчётом — копируется в буфер одним кликом.
- **Авто-подтверждение** 2FA-подтверждений (торги, смена почты и т.п.).
- **Подтверждение входов в Steam** — как в мобильном приложении: одной кнопкой одобряете или
  отклоняете вход с нового устройства.
- **Переименование** аккаунта, **выход** и **удаление**.
- **Прокси для каждого аккаунта** (см. ниже).

### 🤝 Трейды и подтверждения
- Список **входящих и исходящих** предложений обмена.
- **Принять / отклонить** предложение прямо из списка.
- **Авто-приём** трейдов без ручного подтверждения.
- Окно **деталей предложения** (состав, партнёр, статус) в отдельном окне.
- Лента **подтверждений** с кнопкой «Принять все».

### 📦 Массовая отправка предметов
- Выберите предметы из инвентаря и отправьте **нужному аккаунту**.
- **Сохранённые получатели**: SteamID64 или трейд-ссылка + торговый токен.
- Подсказка про ошибку 15 (если получатель не в друзьях и не указан токен).

### 🎮 Контракты CS2 (Trade-Up)
- Просмотр **инвентаря CS2** и исполнение **Trade-Up контрактов** (10 предметов одной редкости)
  через GlobalOffensive Coordinator.
- Расчёт **EV** контракта и **история** исполненных контрактов.
- Режим просмотра **без запуска игры** (аналитика, но крафт отключён).

### 🎒 Инвентарь
- Отдельное окно просмотра инвентаря по игре/контексту, поиск, фильтр «только трейдовые»,
  выделение предметов для массовой отправки.

### 🕹️ Фоновая «игра» в игры
- Подключение к Steam как CM-клиент и **отчёт об играх** без запуска самой игры (как в ASF).
- Выбор `appID` (пресеты CS2 / Dota 2 / TF2 / Rust + свои) и **авто-игра при запуске**.

### 🌐 Прокси (на аккаунт)
- Поле **Прокси** в карточке аккаунта и при добавлении: `socks5://`, `socks4://`, `http(s)://`
  или просто `host:port`. Работают **логин и пароль** (формат продавцов `host:port:user:pass`
  тоже поддерживается).
- Кнопка **«Проверить»** — реальный запрос через прокси и показ вашего внешнего IP (доказывает,
  что трафик идёт через прокси).
- DNS резолвится **на стороне прокси** (без утечки DNS).

### 🎨 Интерфейс и настройки
- **Два языка**: русский и английский.
- **Темы оформления**: набор готовых тем (по умолчанию «Aura», тёмные варианты).
- **Журнал** событий (сворачиваемая панель) для диагностики.
- **Авто-обновление** через GitHub Releases.

## 📥 Установка

1. Перейдите в раздел **[Releases](https://github.com/wuwku6e6/Aura-Auth/releases)** этого
   репозитория.
2. Скачайте файл установщика `Aura Auth-<версия>-setup.exe`.
3. Запустите его и пройдите установку (NSIS). Можно выбрать папку установки.
4. Запустите **Aura Auth** из меню Пуск / ярлыка на рабочем столе.

> 💡 Обновления приходят автоматически: в настройках нажмите «Проверить обновления».

---

## 🚀 Быстрый старт

1. Нажмите **«Добавить аккаунт»** и перетащите в окно файл `maFile` (экспорт из официального
   Steam Guard / SDA-инструментов).
2. Аккаунт появится в списке; рядом с именем — живой **код Steam Guard** (кликните, чтобы
   скопировать).
3. Включите **Автоподтверждение** и/или **Автоприём**, если нужно.
4. Для работы через прокси нажмите на чип **«Прокси»** под именем аккаунта, введите адрес и
   нажмите **«Проверить»**.
5. Чтобы «играть» в игры без запуска — откройте блок **«Играть в игры»**, выберите игры и
   нажмите **«Играть»**.

---

## 🔒 Безопасность

- Ваши ключи 2FA лежат только в локальной папке `maFiles/`. **Не отправляйте эту папку никому**
  и не коммитьте её — она уже исключена из репозитория (`.gitignore`).
- Прокси используется только для сетевого трафика к Steam; он не видит ваши ключи 2FA.

## ❓ Статус функционала

- ✅ Актуально: 2FA, трейды, массовая отправка, CS2 Trade-Up, инвентарь, фоновая игра, прокси по
  аккаунтам, два языка, темы, авто-обновление.
- ❌ Разблокировка ачивок через SAM-хелпер **удалена** (закрывала Steam-клиент).

<details>
<summary>🛠 Для разработчиков — сборка из исходников</summary>

Требуется **Node.js 18+** и **npm**:

```bash
git clone https://github.com/wuwku6e6/Aura-Auth.git
cd Aura-Auth
npm install
npm run dev      # режим разработки (Vite + Electron)
npm run dist     # сборка установщика NSIS в папку release/
```

Папки `node_modules/`, `dist/`, `release/`, `maFiles/` исключены из репозитория.

</details>
